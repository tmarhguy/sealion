[#overview]
[preface]
== SeaLion documentation

SeaLion is a distributed full-text search engine written in Rust. This manual describes its architecture, command-line interfaces, query model, storage format, and verification strategy.

++++
<!-- docs-hero -->
++++

[#quick-start]
=== Quick start

Install https://www.rust-lang.org/tools/install[Rust and Cargo], clone the https://github.com/tmarhguy/sealion[repository], and run these commands from its root directory.

[source,bash]
----
cargo build --workspace
./target/debug/sealion index ./evaluation/corpus --data-dir ./sealion-data
./target/debug/sealion search "distributed systems" --data-dir ./sealion-data
./target/debug/sealion serve --bind 127.0.0.1:8080 --data-dir ./sealion-data
----

Open http://127.0.0.1:8080[localhost:8080] to use the search interface. See <<interfaces,Interfaces>> for command options and configuration.

[#documentation-conventions]
=== Conventions

* `monospace` identifies commands, paths, and code identifiers.
* Paths are relative to the repository root unless stated otherwise.
* Unmeasured results are marked `TBD (unmeasured)`.
* The normative storage specification and design decisions are maintained in `docs/index-format.md` and `docs/adr/`.

The https://github.com/tmarhguy/sealion[repository] contains the source and supporting documents. Use the chapter sidebar to navigate this manual, or press kbd:[Ctrl+K] / kbd:[⌘+K] to search.
